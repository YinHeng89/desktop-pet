# PetBuddy 手动测试清单

> **用途**：覆盖自动化断言不了的"手感"与"平台视觉"类验证。
> **执行时机**：每次发版前；以及重构 Phase 3 / 4 / 7 结束时各执行一次全量。
> **记录方式**：勾选 + 填写实测环境（macOS 版本 / Windows 版本 / DPI / 显示器配置），发现问题直接开 Issue 并回链本条目。

## 1. macOS 专项

> 需在 **macOS 12 / 13 / 14** 三个大版本各测一遍。

### 1.1 穿透与交互

- [ ] **穿透手感**：鼠标移到宠物上可交互（能 hover / 点击）；移开后点击能穿透到下层窗口（Finder / 浏览器）
- [ ] **气泡可交互**：气泡出现时，气泡区域可点击、可拖动；气泡外的透明区穿透
- [ ] **透明区无残留**：宠物/气泡周围透明区无任何可见矩形轮廓或半透明底色
- [ ] **阴影完整**：气泡阴影、宠物 `drop-shadow` 均未被穿透裁切除掉

### 1.2 拖拽

- [ ] **跟手度**：按住宠物拖动，窗口跟随无延迟、无抖动、无"掉帧跳跃"
- [ ] **方向正确**：向左拖播 `runningLeft`，向右拖播 `runningRight`；中途反向能实时切换
- [ ] **单击不被误吞**：轻点（无位移）能触发随机动作 + 台词，不会被判定为拖拽
- [ ] **双击开设置**：双击宠物打开设置窗口，且不会同时触发拖拽
- [ ] **松手不误触发**：拖拽松手后不会误触发单击的随机动作

### 1.3 焦点与窗口层级

- [ ] **不抢焦点**：点击/拖拽宠物时，当前活跃 App（如编辑器）不失去焦点、光标不跳走
- [ ] **始终置顶**：宠物在所有普通窗口之上；进入全屏 App 时行为符合预期
- [ ] **全 Space 常驻**：切换虚拟桌面 → 宠物跟随且**无闪烁**；进入全屏 App → 宠物表现一致
  > ⚠️ 回归点：`macos_pet.rs` 曾因 `UtilityWindow` style mask 导致"个别桌面边框闪烁"
- [ ] **无边框闪烁**：切换 Space / 唤醒屏幕时，宠物窗口不出现系统描边闪一下

### 1.4 Dock 与托盘

- [ ] **开机纯托盘**：启动后 Dock 中**无** PetBuddy 图标，Cmd+Tab 中也不出现
- [ ] **开设置进 Dock**：打开设置窗口 → Dock 出现图标、Cmd+Tab 可切回
- [ ] **关设置退 Dock**：关闭设置窗口 → Dock 图标消失，回到纯托盘
- [ ] **托盘菜单**：图标 + tooltip 正常；菜单项齐全（打开设置 / 显示隐藏宠物 / 开机自启 / 切换宠物 / 退出）
- [ ] **开机自启勾选态**：菜单中勾选状态与实际一致；切换后立即刷新

### 1.5 开机自启

- [ ] 系统设置 → 通用 → 登录项 中可见 PetBuddy
- [ ] 注销重登后自动启动，且带 `--autostart` 标记（不弹设置窗口）
- [ ] 取消勾选后从登录项中移除

### 1.6 显示器

- [ ] **Retina 主屏**：宠物与气泡位置正确、命中区域与视觉一致
- [ ] **外接非 Retina 副屏**：拖到副屏后位置与命中仍一致
- [ ] **分辨率切换**：切换分辨率后宠物不跑出屏幕

## 2. Windows 专项

> 需在 **Windows 10 / 11** × **DPI 100% / 125% / 150%** 三档各测一遍。

### 2.1 区域裁剪（Windows 核心风险）

- [ ] **无窗口轮廓**：气泡出现/消失时，不出现"隐约的 Windows 窗口"方形轮廓
  > ⚠️ 回归点：`main.rs` 中 resize 后未重裁导致露出透明窗口轮廓
- [ ] **隐藏无闪现**：切换「显示宠物」→ 关闭，无窗口边框一闪而过
  > ⚠️ 回归点：`windows_pet.rs` 中 hide 与 `SetWindowRgn` 顺序曾反了
- [ ] **阴影未被裁**：气泡四周阴影完整，无缺角 / 断层 / 硬边
- [ ] **气泡箭头完整**：气泡下方的三角箭头不被裁掉
- [ ] **气泡淡出同步**：气泡本体与箭头**同时**消失，无"箭头晚消失约 120ms"的错位
  > ⚠️ 回归点：`PetHost.vue` 中兜底定时器曾为 340ms，大于淡出动画 220ms

### 2.2 DPI

- [ ] **主屏 100%**：命中区域与视觉一致
- [ ] **主屏 125% / 150%**：命中区域与视觉一致（无偏移）
- [ ] **跨屏拖动**：把宠物拖到与主屏缩放比例不同的副屏 → 命中区域自动跟随，无偏移
  > ⚠️ 回归点：`windows_pet.rs` 中 `GetDeviceCaps`（取主屏 DPI）已被 `GetDpiForWindow` 取代，需验证确实生效
- [ ] **运行中改 DPI**：不重启 App 直接改系统缩放 → 宠物位置与命中自动适配

### 2.3 交互

- [ ] **单击 / 双击 / 拖拽**三种操作互不干扰（Windows 下 `startDragging` 会吞事件，需重点验证）
  - 轻点 → 随机动作 + 台词
  - 双击 → 打开设置
  - 拖动 → 跑步动画 + 窗口跟随，松手后 `dragging` 状态正确复位
- [ ] **拖拽方向**：左右方向判定正确
- [ ] **穿透**：透明区点击穿透到下层窗口

### 2.4 窗口外观

- [ ] **设置窗圆角**：DWM 圆角与 CSS 圆角视觉一致，四角无黑边 / 无白角
- [ ] **设置窗阴影**：有系统投影（无边框窗口默认无投影，需显式开启）
- [ ] **蒙版不溢出**：弹窗蒙版不溢出到窗口圆角外的透明区域（无"四角被深色遮挡"）
- [ ] **任务栏**：宠物不出现在任务栏；设置窗口正常出现并可切换

### 2.5 开机自启

- [ ] 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 存在 `PetBuddy`
- [ ] 值为当前 exe 完整路径（带引号）+ `--autostart`
- [ ] 重启后自动启动且不弹设置窗口
- [ ] 取消后从注册表中移除

## 3. 通用功能（双端）

### 3.1 宠物与动画

- [ ] 内置 3 只（Miku / 龙神丸 / Seedy）动画各自正常，帧不错位、不越界
- [ ] 空闲随机动作间隔自然（6~15s），无长时间静止、无频繁抖动
- [ ] 单击台词与宠物性格匹配（内置三只各不相同）
- [ ] 悬停播 `waiting`，移出回 idle
- [ ] 连续快速切换 ≥5 个宠物：无残影、无错帧、无"上一只停留"
- [ ] 长时间运行（≥8 小时）：无内存泄漏、CPU 占用正常（macOS 静止时应可休眠）

### 3.2 通知

- [ ] `curl -X POST http://127.0.0.1:8756/notify -d '{"text":"测试"}'` → 气泡出现，4s 后消失
- [ ] 带 `action` 时：先播动作再显示气泡（动作不被气泡覆盖）
- [ ] 带 `duration` 时：气泡按指定时长消失
  > ⚠️ 回归点：该参数曾全链路贯通但前端丢弃
- [ ] 连续发 20 条：队列不丢、顺序正确、气泡不叠加、不残留在屏幕上
- [ ] 超过 120 字：返回 400 且 error 文案正确（中文按 1 字符计）
- [ ] 设置窗「测试通知」：发送成功、3s 冷却倒计时正常、curl 示例可复制

### 3.3 设置窗口

- [ ] 首次打开居中；拖动后关闭再打开，恢复到上次位置
- [ ] 关闭是隐藏而非销毁（再次打开速度快、状态保留）
- [ ] 宠物列表：内置 + 外部全部显示，选中高亮
- [ ] 缩放滑块：50%~130%，步进 0.05，拖动实时生效，main 窗口同步缩放
- [ ] 缩放时以**右下角为锚点**：宠物不漂移、不跳位
- [ ] 「显示宠物」开关：联动 main 窗口显隐，重启后保持
- [ ] 窗口任意空白处可拖动；按钮/输入框/滑块/卡片上拖动**不**触发窗口移动
- [ ] 版本号显示正确（与 `tauri.conf.json` 一致）
- [ ] 右键菜单被禁用

### 3.4 导入 / 编辑 / 删除

- [ ] `pet/` 下 9 个 zip **逐个导入成功**，动画正确、无错位
- [ ] 导入后自动切换到新宠物并弹气泡提示
- [ ] 非 zip 文件被拒绝并提示
- [ ] zip 内缺 `pet.json` / 缺 `spritesheet.webp` → 明确错误提示（非静默失败）
- [ ] 编辑外部宠物名字/描述 → 列表与托盘菜单实时更新，重启后保持
- [ ] 删除需**二次点击确认**；3 秒内不确认则自动复位
- [ ] 删除当前选中的宠物 → 自动回退到第一只，且 main 窗口同步切换
- [ ] 非法 id（空 / 含 `../` / 中文）被拒绝

### 3.5 在线画廊

- [ ] 打开画廊能加载列表（网络正常时）
- [ ] 搜索按名字 / 作者 / 分类模糊匹配
- [ ] 下载成功 → 自动切换到该宠物 → 托盘菜单出现该宠物
- [ ] 已下载的宠物卡片显示「重新下载」而非「下载」
  > ⚠️ 回归点：id 与 slug 不一致时该判定失效
- [ ] 下载失败 → 明确错误提示，不卡死在 loading
- [ ] 断网时：显示加载失败而非永久转圈

### 3.6 跨窗口同步

- [ ] 托盘切换宠物 → 设置窗口高亮同步 + main 窗口宠物切换
- [ ] 设置窗口改缩放 → main 窗口实时缩放
- [ ] 设置窗口切换显隐 → main 窗口实时显隐
- [ ] 托盘切换显隐 → 设置窗口开关同步
- [ ] **重启后**：宠物选择 / 缩放 / 显隐 / 设置窗口位置全部保持

### 3.7 升级兼容性

- [ ] 从上一版本升级后：宠物选择、缩放、显隐、设置窗口位置**全部保持不丢失**
- [ ] 首次启动（无任何旧配置）：默认选中第一只宠物、缩放 70%、显示在右下角

## 4. 性能与稳定性

- [ ] 冷启动时间 < 2s
- [ ] 静止时 CPU 占用：< 1%（macOS 应能进入休眠，NSTimer 有输入变化短路）
- [ ] 常驻内存：< 150MB
- [ ] 连续运行 8 小时内存无持续增长
- [ ] 快速连发 50 条通知不崩溃、不丢消息
- [ ] 连续开关设置窗口 50 次无泄漏、无残留监听

## 5. 异常场景

- [ ] 端口 8756 被占用 → 有明确提示（而非静默失效）
- [ ] 断网时打开画廊 → 显示错误，不卡死
- [ ] `app_data_dir` 不可写 → 导入失败有明确提示
- [ ] 磁盘空间不足 → 导入失败有明确提示
- [ ] 宠物文件被外部删除 → 启动时跳过该宠物而非崩溃
- [ ] 精灵图损坏（非有效 webp）→ 跳过或降级，宠物不消失
- [ ] 强制杀进程后重启 → 状态正常，无残留锁文件
